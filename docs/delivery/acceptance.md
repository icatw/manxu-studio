# 验收清单

## 端到端主路径

- [ ] 用户可以创建项目，输入故事梗概和创作偏好。
- [ ] 用户可以生成并修改角色/场景设定，确认后状态持久化。
- [ ] 用户可以生成结构化分镜并编辑字段及顺序。
- [ ] 用户可以为单格发起画面生成，看到真实任务状态。
- [ ] 单格失败不影响其他分镜；用户可以重试。
- [ ] 用户可以修改一格并产生新版本，旧版本可恢复/比较。
- [ ] 页面刷新或重新进入后，项目、任务状态和结果可恢复。
- [ ] 用户可以预览并导出当前确认的分镜成果。

## 质量与安全

- [ ] 浏览器网络请求中没有模型供应商密钥。
- [ ] 表单和模型结构化输出均经过服务端校验。
- [ ] 加载、空、失败、重试和成功状态都有可理解的界面反馈。
- [ ] 角色/场景更新不会静默改写已有分镜和历史生成输入。
- [ ] 导出内容顺序与当前项目状态一致。
- [ ] 手动验证桌面创作工作区和窄屏基本浏览。

## 演示路径

用原创故事“外卖员误把仙门至宝当成超时订单”演示：创建项目 → 确认主角设定 → 生成四格开场 → 修改冲突格对白 → 生成/重绘该格 → 预览并导出。演示时指出真实模型调用、异步状态、人工修改和尚未实现的能力。
