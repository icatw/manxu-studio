# 页面与状态说明

## 1. 作品库

卡片展示作品名称、题材、画风、封面/派生缩略图与更新时间。提供手填新建与「AI 策划新作品」入口；支持打开与删除。

## 2. 新建 / AI 策划

手填路径：标题、梗概、题材、画风。策划路径：创意梗概 → AI 返回可编辑的世界观、角色、话大纲与伏笔 → 确认创建。

## 3. 作品总览

Tabs：章节（话列表、续写下一话、生成摘要、进入工作室/阅读）、设定集（世界观与画风规则）、伏笔。危险删除二次确认。

## 4. 项目工作区

路由 `/projects/:id/studio`。桌面优先三栏：左侧含故事单元切换与创作阶段；中央画布；右侧检查器（含构图、剧情作用、版本与审阅）。

## 5. 角色与场景

列表编辑档案；草稿/已确认；定妆锁定与确认设定分离。生成、保存和确认均有即时反馈。

## 6. 分镜编辑器

画格有序排列；检查器编辑镜头、构图、动作、情绪、对白、剧情作用与提示词；支持增删与排序。

## 7. 阅读页

竖排浏览当前话画格与对白；上下话导航；可返回总览或工作室。

## 8. 导出预览

预览排序与画面；导出 PNG 或制作资料 JSON（EXP：制作预览/资料，非成稿）。

## 9. 成稿排版（阶段 A1，`confirmed`）

> PAGE-01…03 已确认；实现见计划 `0024-page-layout-a1.md`。流程见 [user-flows.md · 阶段 A1](../product/user-flows.md)。

**路由意向**：`/projects/:id/layout/:episodeId`。

**组成**：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 作品名 · 第 N 话 · 「成稿排版」标识；回总览 / 回工作室 / 整话预览 |
| 中央 | 竖条画布：Slot 堆叠；选中、拖拽改序、调格高与间距 |
| 侧栏 | 页/槽缩略序；模板只读说明「竖条漫」；缺图占位提示 |
| 空态 | 无画格 → 引导 Studio；无 Page → 「生成默认竖条页」主按钮 |

**与相邻屏的分工**：

- Studio：分镜与出图（制作态）  
- 阅读页：L1 按分镜序浏览（可继续存在）  
- 成稿排版：持久化 Page/Slot；整话成稿预览  
- 导出预览 / EXP：制作管线下载，文案不得写成「成稿导出」（成稿导出属 A3）

**桌面优先**；窄屏至少可滚动预览与改序，精细调距可降级。

## 全局状态要求

- 页面加载、空数据、保存中、已保存、生成中、失败、离线/服务不可用。
- 长任务支持用户离开再返回后恢复状态。
- 危险操作二次确认，编辑操作有明确保存反馈。
- 窄屏可阅读和执行基本操作；复杂分镜编辑优先适配桌面。
