# 页面与状态说明

## 1. 项目列表

展示项目名称、题材、封面/首张分镜缩略图、更新时间和当前工作状态。主要操作为新建、打开、重命名和删除。空状态直接提供创建入口。

## 2. 新建项目

收集故事标题、梗概、题材、画风和画幅。必填项保持精简；高级偏好可折叠。提交时显示创建状态和字段级错误。

## 3. 项目工作区

桌面优先的创作界面，使用稳定的三栏工作区：

- **左侧导航**：故事、角色与场景、分镜章节。
- **中央画布**：当前阶段内容；分镜阶段显示有序分镜画格。
- **右侧检查器**：当前选中对象的结构化字段、参考资产、生成和版本操作。

各栏职责清晰，避免在对话窗口里混放项目结构、生成结果和编辑表单。

## 4. 角色与场景

列表/画布选择资产，检查器编辑档案。提供草稿、已确认状态；参考图显示来源和关联版本。生成、保存和确认均提供即时状态反馈。

## 5. 分镜编辑器

画格按顺序排列，选择某格后在检查器编辑镜头、动作、情绪、对白和提示词。单格的生成状态、当前图像和版本切换在同一上下文中可见。支持拖动排序，但同时提供可访问的键盘操作。

## 6. 导出预览

展示最终排序和画面，允许选择 PNG 页面布局及制作资料格式。导出前校验未完成任务，并明确是否跳过未完成画格。

## 全局状态要求

- 页面加载、空数据、保存中、已保存、生成中、失败、离线/服务不可用。
- 长任务支持用户离开再返回后恢复状态。
- 危险操作二次确认，编辑操作有明确保存反馈。
- 窄屏可阅读和执行基本操作；复杂分镜编辑优先适配桌面。
