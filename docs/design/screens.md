# 页面与状态说明

## 1. 作品库

卡片展示作品名称、题材、画风、封面/派生缩略图与更新时间。提供手填新建与「AI 策划新作品」入口；支持打开与删除。

## 2. 新建 / AI 策划

手填路径：标题、梗概、题材、画风。策划路径：创意梗概 → AI 返回可编辑的世界观、角色、话大纲与伏笔 → 确认创建。确认后只物化第 1 话；其余大纲写入设定集「规划话大纲」。

## 3. 作品总览

Tabs：话次（话列表；主 CTA「工作室」；摘要常显；「续写下一话」按最早无摘要话引导或新建，新建时预填规划大纲标题/梗概；与工作室侧栏「+」同一 frontier；阅读/成稿排版收入「更多」；顶栏「合集预览」与「合集下载」并列）、**角色**（全剧角色库：定妆/确认状态；说明各话共用同一批人）、设定集（世界观与画风规则；含规划话大纲）、伏笔。危险删除二次确认。产品文案统一用「作品 / 第 N 话」，不用「项目 / 故事单元」。

**合集预览**（COLLECT-PREVIEW-01）：勾选多话 → `/projects/:id/anthology-preview` 连续竖条（布局高度 + Lettering 叠层）；未排版话章节卡「未排版」；缺图格占位。与分镜阅读页区分。

## 4. 工作室（作品工作区）

路由 `/projects/:id/studio`。桌面优先三栏：左侧含话次切换与创作阶段（不含账户壳）；中央画布；右侧检查器（含构图、剧情作用、版本与审阅）。返回总览走顶栏；**账户 / 设置 / 退出**统一在顶栏右上角头像菜单（与作品库、总览、成稿排版一致）。

**故事创意页**（EP2）：本话标题/梗概可编辑；「连载上下文」只读块展示本话规划原文（可一键填入梗概）、将注入的前情摘要（仅更早话）与未回收伏笔；文案标明生成分镜不改梗概。侧栏「+」与总览「续写」同一摘要 frontier；通过门禁后传占位梗概，由服务端按规划大纲预填。

## 5. 角色与场景

列表编辑档案；草稿/已确认；定妆锁定与确认设定分离。生成、保存和确认均有即时反馈。

## 6. 分镜编辑器

画格有序排列；检查器编辑镜头、构图、动作、情绪、对白、剧情作用与提示词；支持增删与排序。

## 7. 阅读页

竖排浏览当前话画格与对白；上下话导航；可返回总览或工作室。

## 8. 制作预览与导出

Studio 顶栏：「制作预览」（**字效主编辑面** + 分镜序条漫）、「成稿排版」、「制作导出 ▾」（长图 / 分页 ZIP / 制作资料；EXP，非成稿）。分镜阶段且已有脚本时，顶栏另有次要「重写分镜脚本」（非出图）。故事页承担首次「生成角色与分镜 / 生成本话分镜脚本」；分镜空态保留本地「生成分镜脚本」。作品场景空态主 CTA「根据本话生成场景」，暖态可追加/补参考图；分镜页在无场景时软提示。侧栏分镜列表仅在分镜阶段展开。成稿页用「成稿预览」；作品总览用「合集下载」。

**制作预览对话框**（LETTER-03）：

| 区域 | 内容 |
| --- | --- |
| 顶区 | 「从分镜生成气泡」；多人拆泡且落库无说话人前缀；壳词「无对白。」不种；说明有字效用字效、无则对白占位 |
| 条漫 | 底图 + Lettering 叠层（可点选）；无字效时虚线对白占位 |
| 侧栏/底栏 | 选中字效：文案、位%、宽%、字号、增删气泡/旁白；有字效时「一键布局」：顶栏 / 左右对谈 / 底部条（LETTER-08，只改几何） |

画布分镜卡与制作预览共用叠字规则。EXP 烘焙同规则。

## 9. 成稿排版（阶段 A1，`confirmed`）

> PAGE-01…03 已确认；实现见计划 `0024-page-layout-a1.md`。流程见 [user-flows.md · 阶段 A1](../product/user-flows.md)。

**路由意向**：`/projects/:id/layout/:episodeId`。

**组成**：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 作品名 · 第 N 话 · 「成稿排版」；编辑 / 成稿预览 / **导出成稿 ▾** / 回工作室 |
| 中央 | 竖条画布：Slot 堆叠；选中、拖拽改序、调格高与间距；字效只读叠层 |
| 侧栏 | 页结构说明；引导「回工作室制作预览改字效」；缺图占位提示 |
| 空态 | 无画格 → 引导 Studio；无 Page → 「生成默认竖条页」主按钮 |

**与相邻屏的分工**：

- Studio：分镜、出图、**字效主编辑**（制作预览）；**制作导出**（EXP）  
- 阅读页：L1 按分镜序浏览（可继续存在）  
- 成稿排版：Page/Slot 页结构、成稿预览、**导出成稿**（PUBLISH）  

**桌面优先**；窄屏至少可滚动预览与改序，精细调距可降级。

## 10. 成稿字效（阶段 A2 / LETTER-03，`confirmed`）

> LETTER-01…03；实现见计划 `0025`、`0026`。流程见 [user-flows.md · 阶段 A2](../product/user-flows.md)。

**主编辑在工作室制作预览**；成稿排版不另开字效主路由：

| 区域 | 内容 |
| --- | --- |
| 工作室制作预览 | 种气泡、增删改字效、**桌面拖位置**、一键布局模板（LETTER-08）、条漫叠字 |
| 工作室分镜列表/检查器 | 有字效时摘要跟字效；对白字段标制作态；可回写脚本（LETTER-07） |
| 成稿排版 | 页结构为主；字效只读/次要 |
| 成稿预览 | 底图 + 叠字；标明含字效 |

**不做**：页级游离字效、字体上传。

## 全局状态要求

- 页面加载、空数据、保存中、已保存、生成中、失败、离线/服务不可用。
- 长任务支持用户离开再返回后恢复状态。
- 危险操作二次确认，编辑操作有明确保存反馈。
- 窄屏可阅读和执行基本操作；复杂分镜编辑优先适配桌面。
