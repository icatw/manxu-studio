# 竞品调研与差异分析

> **调研日期**：2026-10-17  
> **对象**：国内 AI 漫画 / 漫剧 / UGC 漫画工具，对照漫序 Studio（本仓库）  
> **方法**：公开官网、FAQ、产品文案与第三方综述；**未做付费完整试用与画质盲评**。结论供产品定位，不构成收入或质量断言。  
> **权威产品范围**仍以 [prd.md](prd.md)、[brief.md](brief.md)、[roadmap-complete-comic.md](roadmap-complete-comic.md) 为准。

## 1. 一句话结论

| 维度 | 判断 |
| --- | --- |
| 赛道 | 国内「文字 → 漫画」工具已密集；多数卷**一键出图 / 批量出片 / 视频漫剧**，少数做**可审阅的连载工作台**。 |
| 漫序位置 | **个人静态连载工作台**：跨话设定、伏笔/摘要、先审分镜再出图、版本与制作导出；成稿层（PAGE 已有，LETTER/PUBLISH 在路上）。 |
| 最近邻 | [漫页 Studio](https://manye.cc/)（流程高度重叠，商业化更完整）；[德学漫画](https://comic.dexuebao.com/)（多端 + 批量 + 视频导出，偏效率 SaaS）。 |
| 不直接撞车 | [DramaBuddy](https://aicomic.yuewen.com/)（网文 IP + 视频漫剧 + 工作室生态）；[触漫](https://www.cocomix.cn/)（素材拼搭 UGC 社区）；[鲸先生](https://mrwhale.ai/)（对话式短漫 / 图像矩阵 + 阅读社交）。 |
| 应坚持的差异 | **连载上下文与作者可控修改**（不是「一次生成整本」）；**静态成稿 + 独立文字层**（不是视频工厂）；**个人作品可带走**（不是社区素材商城）。 |

| 项 | 现状（2026-10） |

## 3. 竞品逐个画像

### 3.1 漫页 Studio（manye.cc）— 最近邻

| 项 | 内容 |
| --- | --- |
| 官网 | https://manye.cc/ |
| 定位文案 | 「把你的故事，画成连续漫画」；小说/故事 → 连续漫画 |
| 公开能力 | 画风模板选择；角色与分镜确认；单页重绘/重试；对白可调（若字已画入图则需重绘）；全部图 ZIP 导出；免登录官方漫画节选 |
| 商业化 | 新用户体验积分（如 100 分/7 天）；创作者月度套餐约 **¥29.9/30 天**（含积分、云空间、并发任务）；可加购积分 |
| 形态 | Web SaaS；闭环偏「短故事试生成 → 付费续作」 |
| 与漫序 | **流程几乎同构**（故事→角色/分镜→出图→ZIP）。漫页在**落地页包装、画风样张、积分 VIP、官方样刊阅读**上更完整；漫序在**多话连载资产（伏笔/摘要/季策划）、定妆锁定与版本、BYOK、成稿页模型**上更深。命名相近（漫页 / 漫序），对外需刻意区分叙事。 |

## 6. 与漫序的差异摘要

### 6.1 我们相对清晰的优势（可写进叙事）

1. **连载工作台深度**：季策划、伏笔、话摘要前置、作品设定集——公开材料里多数竞品只做到「项目/章节」，少见同等「跨话连续性」产品化。  
2. **作者控制权**：先结构化分镜再出图；单格版本历史；重绘不默默毁掉整页（PAGE 保布局；LETTER 目标改字不重绘）。  
3. **静态成稿方向明确**：EXP / PUBLISH 双轨；不把自己说成视频工厂。  
4. **模型侧灵活**：账户 BYOK（文本 + Qwen Image 配置），适合进阶作者；竞品多为封闭积分池。  
5. **边界诚实**：不承诺绝对角色一致、不做团队/社区首发——降低与 DramaBuddy / 触漫的错位预期。

### 6.2 我们相对明显的短板（公开对比）

| 短板 | 对标 | 影响 |
| --- | --- | --- |
| 商业化与试用闭环弱 | 漫页 VIP/积分；德学充值 | 转化与「先试后买」叙事不足 |
| 批量出图 / 推文效率 | 德学、DramaBuddy | 工作室产能客户难抢 |
| 多端客户端 | 德学、触漫 | 移动创作场景弱 |
| 视频与发行生态 | DramaBuddy、德学、鲸影 | 不能也不应跟进为近端主线 |
| 成稿层仓库已齐、生产未解冻 | 触漫文字编辑；漫页「改对白」体验 | 对外仍按 tag 话术；先打磨制作再谈上线 |
| 品牌与样刊 | 漫页官方节选；阅文作品墙 | 信任与「好看」证明弱 |
| 命名易与「漫页」混淆 | manye.cc | 对外需固定「漫序 Studio + 连载工作台」 |

### 6.3 按竞品的「学 / 避」

| 竞品 | 可学 | 应避 |
| --- | --- | --- |
| 漫页 | 落地页画风样张、积分预估、失败页单重试文案、ZIP 交付清晰 | 被拖成「又一个积分出图站」；忽视连载差异 |
| 德学 | 批量与导出格式清单、FAQ 教育「先角色后出图」 | 视频主路径、卡密工作室复杂度抢跑 |
| 鲸先生 | 竖屏比例与「一句话」获客；产品矩阵拆分清晰 | 社交阅读作为留存前提；对话替代审阅工作流 |
| DramaBuddy | 拆书与分集结构体验；额度可视化（远期 SaaS） | IP 生态、无限画布、视频 Agent 作为对标 KPI |
| 触漫 | 气泡/对白编辑心智；低门槛完成感 | 素材商城与社区 UGC 主战略 |

## 7. 对路线图的含义（建议，非需求授权）

> 下列不升格 PRD；实现仍须 `confirmed` + OpenAPI。

1. **阶段 A 已齐后，优先 A′ 制作打磨**（对白→字效、重绘保字、竖条观感），再谈上线话术；独立文字层已回应「对白画进图只能重绘」。  
2. **阶段 B 连载加厚**在「一话做得顺」之后强化护城河（设定变更影响、第二话体验）。  
3. **阶段 C SaaS**：积分预估 / 套餐或「BYOK 主叙事」二选一写清，否则难与漫页/德学同台讲价。  
4. **不做**：为对齐 DramaBuddy 上视频；为对齐触漫上社区——除非单独验证。  
5. **对外话术**：固定「个人连载静态漫画工作台」；对比句式用「跨话设定与审阅掌控」，少用「AI 漫画生成器」这种红海标签。
