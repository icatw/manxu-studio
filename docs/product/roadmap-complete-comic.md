# 漫序 Studio：个人连载漫画工作台路线图

> **规划状态：产品方向已收敛，阶段功能仍须逐项通过 PRD 确认。** 本文是产品路线，不授权将 `proposed` / `deferred` 需求直接实现。开发前按 PRD 建立或确认需求，再完成 OpenAPI YAML 评审。
>
> 定位与产品分层修订：2026-10-17。竞品描述基于公开材料，不代表独立质量或收入验证。

## 一句话定位

漫序 Studio 是一款面向个人连载作者的 **静态图片漫画创作工作台**：带着作品设定与角色，一话接一话；先审分镜，再出画格，再排成可读条漫并导出。

首阶段：个人账户 + 个人作品。不以团队制作公司或视频工厂为主要客户。

## 产品要解决的核心问题

单张出图撑不起连载：人设漂移、前情反复交代、重绘破坏已有成果、模型绘字难以改。

优势应落在：**连载上下文 + 作者可控修改 + 可带走的静态成品**。角色一致靠设定/参考/审核改善，不是绝对保证。

## 产品四层（规划主结构）

| 层 | 用户得到什么 | 现状 |
| --- | --- | --- |
| **L1 连载工作台** | 作品/话、设定、伏笔摘要、分镜、出图、版本、制作预览导出（EXP） | **已交付**（`v0.1.0-storyboard`） |
| **L2 成稿层** | 可存的页/条漫布局 + 独立文字对象；改字不重绘 | **PAGE + LETTER 已交付**（仓库；生产冻结） |
| **L3 成稿交付** | 成稿导出语义；可选私密评审链接 | **PUBLISH-01 已交付**；PUBLISH-02 仍 `proposed` |
| **L4 SaaS 产品面** | 个人工作室心智：用量/套餐、带走与删除、身份恢复 | 账户骨架已有；包装与账本未立 |

**SaaS 个人漫画制作平台** = L1 为底座 + **优先建成 L2**，再补 L3/L4 最小集。没有 L2，产品停留在分镜工具；有 L2，才站得住「做漫画」。

## 领域关系（成稿叠在分镜上，不替换）

```text
Project（作品）
  └── Episode（话）
        ├── StoryboardPanel / PanelVersion / 图像资产     ← L1 已有
        ├── Page（页/条段落，有序）                      ← L2 已交付
        │     └── PageSlot → 引用 PanelVersion
        └── LetteringObject（气泡/旁白…）               ← L2 已交付（挂 Slot）
              └── 与底图分层存储；主编辑在工作室制作预览
Export
  ├── EXP_*     制作预览 / 制作资料（可烘焙气泡）       ← L1 已有
  └── PUBLISH_* 成稿合成导出（文字层 + 布局）           ← L3 PUBLISH-01 已交付；-02 proposed
```

原则：重绘 Panel 默认保留 Page 布局与 Lettering；模型绘字不得作为唯一对白源。

## 完整体验定义

同一作品内：整理故事与设定 → 规划话并复用角色/前情 → 审分镜 → 出图与版本 → **排竖条漫并独立编辑对白** → 整话预览与成稿导出 → 继续下一话。

「完整」= 一话可读可带走；≠ 自动写完长篇、视频或专业出版排版。

## 当前基线与缺口

**已有（L1）**：多话、设定集、角色/场景、季策划、伏笔、摘要、分镜、异步出图、版本、阅读页、EXP 长图/分页 ZIP/JSON/合集。

**缺（L2）**：可持久化页模型；独立文字层；成稿预览与成稿导出产品化。

运维与 COS 等见 `.harness/status.md` / `saas-readiness.md`；**不替代**成稿产品主线。

## 产品原则与边界

- 静态图；**MVP 只做竖条漫**；页漫网格后置。
- AI 提案、作者定稿；不包装成一次生成整部连载。
- 项目级设定与摘要是资产；改设定应标影响，不静默改史。
- 对白/旁白可独立编辑；模型绘字非唯一来源。
- 默认可带走；不以公开社区为留存前提。
- 作品默认私有；分享须主动开启且可撤销。

不做（近端）：动态漫/视频、公开发现社区、无限画布、印刷级排版全家桶、多组织席位与实时协作。

## 产品主线分期（能力顺序）

> 以下为**产品能力顺序**。需求在 PRD 升为 `confirmed` 并 YAML-first 前不得实现。

### 阶段 A — 成稿最小闭环（当前产品主目标）

目标：从已确认分镜走到「一话可读条漫」。

| 子阶段 | 能力 | PRD |
| --- | --- | --- |
| **A1** | Page 模型；竖条模板（序/距/高）；整话成稿预览；重绘默认保布局 | PAGE-01…03 **`confirmed`**；契约已入 OpenAPI |
| **A2** | Lettering 对象；**主编辑在工作室制作预览**；成稿排版管页结构；改字不重绘；EXP 有字效则烘焙字效（成稿导出属 A3） | LETTER-01…03 **`confirmed`** |
| **A3** | 成稿导出（长图、多页 PNG/PDF）；与 EXP **双轨文案** | PUBLISH-01（CBZ 另验） |

**阶段 A 验收（产品语言）**：改一句对白或重绘一格后，其余格与排版仍在；成稿导出中文可读、顺序正确；用户能区分「制作预览（EXP）」与「成稿（PUBLISH）」。

### 阶段 A′ — 制作打磨（已收口；计划 `0028`）

A1–A3 能力已齐后、**先于发布与阶段 B**，用对照压测收制作摩擦：对白→字效、出图/重绘、竖条观感、第二话接着做。只升格阻塞「做好一话」的需求；PUBLISH-02 / 解冻生产 / 社区不进本阶段。**2026-10-19 收口**：F01–F08 / F04–F07 已关闭；F09（画布挤）deferred。

### 阶段 B — 连载质量加厚

设定/角色变更影响提示；第二话体验收束；草稿恢复等。在 A′ 打磨证明「一话做得顺」之后加厚差异。

### 阶段 C — SaaS 产品面（个人工作室）

可与 A **并行设计**，实现优先级低于 A，除非阻塞「个人资产归属」叙事：

- 身份绑定/恢复（AUTH-07）
- 用量估算与成功/失败/重试规则
- BYOK vs 平台额度：**先定一种主推叙事**（影响信息架构，不阻塞 A1）
- 作品带走与删号
- 私密评审链接（PUBLISH-02，宜在成稿之后）

### 阶段 D — 有证据再扩展

页漫增强、外部平台格式、可选公开阅读、轻量协作——每项单独验收，不因竞品自动进排期。

```text
L1（已有）
  → A1 Page + 竖条 + 成稿预览
  → A2 Lettering
  → A3 成稿导出产品化
  → A′ 制作打磨（已收口；F09 deferred）
  → 阶段 B 连载质量加厚（候选）   ← 下一步产品主线
  → B 连载质量
  → C SaaS 面最小集（可穿插设计）
  → D 扩展
```

运营向的「试用基线 / 作者验证 / 付费」见文末附录与 [saas-readiness.md](../technical/saas-readiness.md)。**产品主线以阶段 A–D 为准**；不把邀测当作启动成稿层的前置条件。

生产应用更新在 `v0.1.0-storyboard` 后默认冻结，直至显式解除（见 `.harness/status.md`）。

## 规划期须钉死的产品决策

1. MVP 版式：仅竖条漫。  
2. 文字所有权：Lettering 为对白真源。  
3. EXP 保留为制作管线；成稿走 Page + Lettering + PUBLISH。  
4. SaaS MVP 定义：个人账户 + 多作品 + L1 + 阶段 A；团队/社区不做。  
5. 计费叙事：BYOK 或平台额度择一为主（写入 C，不挡 A1）。

## 市场与竞品观察（摘要）

国内静态漫画工具已存在但市场证据分散。[漫页](https://manye.cc/)、[德学漫画](https://comic.dexuebao.com/)、[鲸先生](https://mrwhale.ai/)、[DramaBuddy](https://aicomic.yuewen.com/)、[触漫](https://www.cocomix.cn/) 等与漫序有不同程度重叠；另有 [智漫工坊](https://apps.apple.com/cn/app/%E6%99%BA%E6%BC%AB%E5%B7%A5%E5%9D%8A-ai%E5%88%9B%E4%BD%9C%E6%BC%AB%E7%94%BB/id6777452527)、[GenToon](https://www.gentoon.ai/zh-CN) 等。漫序差异应强调**跨话设定/审阅掌控 + 文字层成稿**，而非只卷「一键出图」。完整矩阵、定位地图与学避建议见 [competitive-analysis.md](competitive-analysis.md)。

## PRD 对应

权威需求在 [prd.md](prd.md)：

- PAGE-01…03 **`confirmed`**（A1 可实现）  
- LETTER-01…03 已 `confirmed`（实现见计划 `0025`、`0026`）

基础设施与 AUTH 不挂靠扩大 PAGE 范围。

## 对外说明边界

可称：「个人连载漫画创作工作台（分镜与画格阶段）」。  
交付前不得宣传：独立对白层、可编辑页布局、完整成稿发布已上线。角色一致用「辅助保持」，不用「保证不变脸」。
