# 长期目标：完整漫画（成刊层）

> **状态：长期目标 / 规划中。**  
> 本文档描述产品愿景与分期路线，**不授权当前实现**。需求进入开发前须在 [prd.md](prd.md) 将对应 ID 从 `proposed` 升为 `confirmed`，并按 YAML-first 更新契约。

## 为什么单独成文

当前已确认范围是 **AI 漫剧预制作**：故事、设定、分镜格图、制作资料导出。  
产品长期期望是：同一作品上，用户能做出 **一本可阅读、可导出的完整漫画**，而不是停在「一叠分镜图」。

预制作与成刊是两层，不是二选一：

```text
预制作（已确认，当前主路径）
  故事 / 设定 / 分镜格 / 参考图 / 制作导出
        ↓ 叠加，不推翻
成刊层（长期目标，本文）
  页排版 / 气泡独立层 / 成稿导出 / 可选分享阅读
```

## 「完整漫画」最低完成定义

用户在同一作品内能够：

1. 讲完故事（多话连载与摘要门禁已具备大半）。
2. 角色跨格可辨认（定妆与参考图已具备）。
3. **成页**：分镜格进入页布局；默认优先 **竖条漫**，页漫为可选模板。
4. **字效独立层**：对白/旁白可改，不依赖模型「画字」、不强制重绘底图。
5. **成稿交付**：至少支持长图 / 多页 PNG 或 PDF，可选 CBZ；可选只读分享链接。

满足以上即算长期目标的最小「一本漫画」。精美手写字效、印刷级出血、公开社区、视频成片 **不在** 本目标内。

## 与当前非目标的关系

[prd.md](prd.md) 非目标中的「专业级漫画排版全家桶」「公开读者社区」「视频成片」仍然成立。  
本长期目标只开放 **有限成刊能力**（排版模板 + 气泡层 + 导出/分享），不扩展为排版软件或内容社区。

## 分期路线（依赖顺序）

| 阶段 | 性质 | 内容 | 验收直觉 |
| --- | --- | --- | --- |
| **底座** | 长期目标的前置（SaaS 稳托） | 对象存储、AUTH-07、生产邮件、配额；建议同步只读分享基础设施 | 真人连用数据不丢、账号可自助 |
| **成刊 MVP** | **长期目标核心** | 页模型、条漫排版、气泡层、成稿导出 | 一话可当成「可读漫画」交出去 |
| **成刊增强** | 长期目标深化 | 阅读方向、设定影响提示、版本对比、分享链接体验 | 改一格不打乱整话成页 |
| **可选商业化** | 更后 | Credits/席位、轻量协作、章节导入、导出到外部出片工具 | 有留存再开 |

**刻意不做（长期仍排除）：** 自动视频成片、公开读者社区、多媒介全家桶、与国内 AI 漫剧工厂比日更冲榜。

## 需求 ID 索引（均为 `proposed`）

权威条目写在 [prd.md](prd.md)「长期目标」一节，此处仅索引：

- **PAGE-01…03**：页模型、条漫/页漫模板、格入槽与顺序。
- **LETTER-01…02**：气泡/旁白独立层；改字不重绘。
- **PUBLISH-01…02**：成稿导出（含可选 CBZ）；只读分享链接。

## 产品原则（成刊层同样遵守）

1. 创作者掌握决定权；生成与排版结果都可改。
2. 设定与分镜资产仍是成页输入，成刊不得绕过已确认设定。
3. 局部修改优先：重绘单格、改单句对白，不应毁掉整页布局。
4. 能力如实呈现：成刊能力上线前不得在文案中宣称「已可出完整漫画」。
