# 漫序 Studio：个人连载漫画工作台路线图

> **规划状态：产品方向已收敛，阶段功能仍须逐项通过 PRD 确认。** 本文是产品路线，不授权将 `proposed` / `deferred` 需求直接实现。开发前按 PRD 建立或确认需求，再完成 OpenAPI YAML 评审。
>
> 定位调研日期：2026-10-17。竞品描述基于公开产品页和应用商店材料，仅反映其公开宣称的功能，不代表独立质量、活跃用户或收入验证。

## 一句话定位

漫序 Studio 是一款面向个人连载作者的 **静态图片漫画创作工作台**：让作者带着自己的作品设定和角色，从一话接着一话创作；先审分镜，再生成画格，最后排成可读漫画并导出。

优先服务两类人：

- 独立漫画作者，希望更稳定地更新原创连载。
- 小说、网文或剧本作者，希望把自己的故事改编为可控、可持续更新的条漫。

首阶段采用个人账户和个人作品，不以团队制作公司或视频工厂为主要客户。

## 产品要解决的核心问题

单张图片生成无法承载长篇漫画：人物和世界观容易漂移，故事要反复交代，重绘一格可能破坏已有成果，模型画入图片的文字又难以准确修改。

漫序的核心优势应该落在 **连载上下文 + 作者可控的修改流程 + 可携带的静态漫画成品**。角色一致性是通过作品设定、角色参考和作者审核来改善的产品能力，不是对生成结果的绝对保证。

## 完整体验定义

一个个人作者可以在同一作品中：

1. 写入或整理故事，建立世界观、角色、场景、画风等作品设定。
2. 规划新话，复用角色和场景，引用前情摘要与未回收伏笔。
3. 生成并人工修改结构化分镜，在出图前确认剧情、对白和镜头顺序。
4. 逐格生成静态画面，重绘单格、保留历史并选择当前版本。
5. 将画格排成适合手机阅读的竖向条漫；对白和旁白以独立文字对象编辑。
6. 预览完整一话，导出图片或 PDF，并能回到作品继续创作下一话。

「完整」指一话能被阅读和带走，不意味着自动写完一部长篇、生成视频或替代专业出版排版。

## 当前产品基线

已具备的工作流包括作品与多话管理、作品设定集、角色和场景复用、季策划、伏笔、摘要与连续性注入、可编辑分镜、异步画格生成、任务恢复、画格版本、长图/分页 ZIP/制作资料 JSON 与跨话合集导出。

当前缺的主要是**成稿层**：可持久化的页/条漫布局，以及不烘焙进底图的对白、旁白文字层。对象存储生产切流和 SaaS 运营事项属于稳定运营基础，不是成稿功能；以 `.harness/status.md` 和 Phase A 计划记录的当前线上状态为准。

## 市场与竞品观察

国内直接做静态漫画创作的公开产品已经存在，但公开证据呈现的是早期、分散的市场，尚不能据此认定已经有单一成熟平台占据个人连载工作台心智。

| 产品 | 公开资料显示的静态漫画能力 | 对漫序的启发 |
| --- | --- | --- |
| [漫页 Studio](https://manye.cc/) | 小说正文、模板、角色与分镜确认、AI 漫画图片、单页重绘、ZIP 图片包；公开提供积分、云空间和创作并发套餐。 | 正文到连续漫画、单页重绘和积分预估是直接重叠区。漫序需要把跨话设定/伏笔/摘要和作者掌控讲清楚。 |
| [智漫工坊](https://apps.apple.com/cn/app/%E6%99%BA%E6%BC%AB%E5%B7%A5%E5%9D%8A-ai%E5%88%9B%E4%BD%9C%E6%BC%AB%E7%94%BB/id6777452527) | 应用商店介绍角色库、剧情转分镜、单格或批量出图、页面排版、对白和导出。公开评分样本很少，实际用户规模未知。 | 页面排版、文字编辑、模型可配置是用户能直接比较的基础能力。 |
| [GenToon](https://www.gentoon.ai/zh-CN) | 四格、竖屏条漫、角色复用、自动分镜与对白；中文产品可用，其公开主体资料显示为韩国运营。 | 一键快速生成和连续角色是强竞争点；漫序不应只讲“角色一致”或“自动生成”。 |

以上资料不足以估算国内市场规模、真实留存或产品质量。当前应把“作者是否会用同一作品连续做第二话”作为待验证假设，而非把功能数量或竞品数量当作市场证明。

## 产品原则与明确边界

- **格式**：静态图片漫画。默认优先竖向条漫；分页漫画在验证页模型后再纳入。
- **创作模式**：AI 提案、作者审阅和修改、作者决定定稿；不把一次生成包装成完成的长篇连载。
- **连续性**：项目级角色/场景设定和话间摘要是重要数据资产；修改设定时标出受影响内容，不静默改写历史。
- **文字**：最终对白和旁白可独立编辑；图像模型画字不能成为唯一文本来源。
- **携带性**：至少导出阅读成品和通用制作资料；不以公开发布社区作为留存前提。
- **隐私**：作品默认私有；分享链接需作者主动开启，可撤销，并明确下载/转发边界。
- **成本**：生成前显示估算，失败与重试的消耗规则可理解；不宣传无限生成。

明确不做：动态漫/视频生成与剪辑、公开读者社区和推荐分发、通用无限画布绘图套件、印刷级专业排版全功能、多组织/席位系统和实时多人编辑。这些只有在目标作者反复提出且商业验证成立后才重新评估。

## 分阶段路线

| 阶段 | 目标 | 主要工作 | 进入下一阶段的证据 |
| --- | --- | --- | --- |
| **0. SaaS 可试用基线（当前）** | 让邀请制作者能稳定使用 **线上 tag 能力**（分镜/画格） | **不挡邀请试用**：密钥轮换、本机构建验证镜像（生产应用更新默认冻结）。**挡开放注册**：AUTH-07、生产邮件、删除/导出说明。**挡收费/代付**：用量账本、配额、备份演练。导出 blob 迁出可并行设计。详见 [saas-readiness.md](../technical/saas-readiness.md)。 | 邀请作者能在 tag 能力上稳定登录创作；开放注册/收费缺口清单关闭情况可核对。 |
| **1. 个人连载作者验证** | 证明用户需要的是连续创作，而非一次性出图 | 与阶段 0 **并行**：邀请独立作者用**当前线上**做连续两话；话术只承诺分镜/画格与制作预览导出，不成稿层。观察设定复用、摘要、分镜审阅、局部重绘、EXP 导出。 | 至少一批目标作者能独立完成两话并复用作品资产；付费意愿有记录。样本数在招募前登记。 |
| **2. 静态漫画成稿 MVP** | 从已确认分镜交付一话可读漫画 | 页/条漫模型；竖向条漫模板；画格顺序、间距和尺寸；对白/旁白独立层；气泡基础样式和文字布局；改对白不重绘画面；完整话预览与长图、多页 PNG/PDF 导出。 | 作者可以完成并导出一话；修改对白、重绘一格后其他画面和布局仍保持；中文文字可读且顺序正确。 |
| **3. 连载质量与个人付费** | 让重复创作值得持续使用和付费 | 版本/设定影响提示；恢复草稿；章节导入质量改进；按模型/操作的用量账本与成本说明；简单个人订阅或积分购买；可撤销的私密评审链接。先处理单人购买，不引入席位。 | 连续创作留存和付费意愿在试用 cohort 中得到验证；平台代付模式下单个付费用户的单位经济可接受；BYOK 模式下用户仍能顺利完成工作流。 |
| **4. 有证据再扩展** | 回应真实创作者需求 | 分页漫画增强、外部平台格式、可选公开阅读入口；轻量协作仅在个人作者常与编辑/画师交接时考虑。 | 每项扩展都有已观察到的用户行为/付费需求和独立验收，不因竞品宣传而自动进入排期。 |

阶段 0 工程可在仓库推进，但 **`v0.1.0-storyboard` 之后默认不部署生产应用更新**，直至显式解除冻结。阶段 1 用线上既有能力并行验证；不要等成稿编辑器或全部基础设施做完才接触作者。

## SaaS 商业验证策略

- 邀请制试用先验证激活、第二话复用和导出行为；公开注册不是目标本身。
- 尽早记录文本/图像操作、模型、估算和实际消耗。成本账本和额度保护属于平台代付前置；复杂订阅、发票和席位按付费验证逐步增加。
- 先比较两种方案的用户摩擦和成本：BYOK（作者自带模型配置）与平台托管额度。不要在需求未验证前承诺无限量或固定单话价格。
- 收费前说明内容保留/删除、模型供应商处理、商业使用边界、退款/失败计费规则和用户数据导出路径。
- 面向中国个人作者时，支付方式、实名/发票、内容合规、隐私条款和生成素材授权范围需在收费前单独验证并完成运营准备。

## 核心指标

先建立基线，再定数值门槛：

- **首次价值**：新作者从创建作品到完成第一话可读导出的时间与完成率。
- **连载复用**：开始第二话的比例；第二话角色/场景复用情况；前情摘要是否被采用。
- **作者控制**：分镜编辑、局部重绘、版本回退和手动确认的使用情况；失败后恢复完成率。
- **质量**：作者对剧情遗漏、角色漂移、对白准确和中文可读性的反馈。
- **SaaS 经济性**：单个完成话数的文本/图像成本、失败重试成本、存储增长、付费转化与退款原因。
- **信任**：数据导出/删除请求完成率、任务状态可恢复率、隐私或计费投诉。

点赞数、生成图数量和注册数不能单独证明产品价值；更强信号是作者完成并继续下一话。

## PRD 对应需求

权威需求和验收仍记录在 [prd.md](prd.md)。以下成稿需求继续保持 `proposed`，不能据此直接实现：

- **PAGE-01…03**：页模型、竖条漫/分页模板、格布局和顺序。
- **LETTER-01…02**：对白/旁白独立对象、样式持久化、编辑文字不重绘底图。
- **PUBLISH-01**：成品长图、多页图片、PDF，CBZ 需单独验证需求。
- **PUBLISH-02**：私密、可撤销阅读链接；公开阅读/发现页不在范围。

账户身份绑定、导出 blob 存储、生产邮件、额度和运行状态各自按其 PRD/基础设施需求管理，不挂靠 PAGE/LETTER/PUBLISH 扩大范围。

## 对外说明边界

当前可以称为「个人连载漫画创作工作台（分镜与画格阶段）」。独立对白层、可编辑页布局、完整成稿发布在交付前不得宣传为已上线。角色一致性使用“复用设定和参考图辅助保持”，不使用“保证不变脸”。
