# 核心用户流程

## 当前主流程：个人连载到画格交付

### 1. 创建故事

用户可手填标题与梗概直接创建作品，或走 AI 季策划：输入创意 → 确认世界观/角色/大纲/伏笔 → 创建作品并进入作品总览。从总览进入某一话的工作区。

### 2. 建立视觉设定

用户从故事生成角色和场景档案。可以逐项修改外观、服装、性格和场景特征；用户确认后，状态显示为“已确认”，作为后续生成上下文。

角色档案可生成参考图。参考图版本与档案版本关联，替换参考图时保留旧版本。

### 3. 生成分镜脚本

用户选择故事范围、分镜数量和节奏倾向。系统基于故事及已确认设定生成分镜草稿。用户先审阅文本结构，可逐格编辑，也可以指定某一格重写。

### 4. 生成分镜画面

用户为选中的分镜发起生成。系统显示任务状态；用户可离开页面后返回查看。成功后将画面保存为该格的新版本；失败时显示原因并提供重试。

### 5. 局部修改与确认

用户可修改画面描述、对白或参考资产，再仅重绘当前格。旧版本保留，用户可比较并选定当前版本。确认后该格进入“已确认”。

### 6. 预览与交付

用户在页面预览顺序、对白和图像，调整分镜次序后导出。可选：本话竖向长图 PNG、本话按页高自动分页的 PNG ZIP、或制作资料 JSON。跨话合集在作品总览导出。导出使用当前选定版本。亦可进入阅读页竖排浏览当前话。

### 7. 续写下一话

用户在作品总览为当前话生成摘要后，再创建下一话并生成分镜。第 N 话（N>1）生成分镜前若上一话无摘要则被拒绝。生成时注入前情摘要与未回收伏笔。本话默认复用作品级角色/场景库；需要新人时以追加方式补充。整队重建角色或场景须单独确认。总览可「导出合集」勾选多话，下载 PNG ZIP 或 PDF。

## 规划流程：个人连载漫画创作

> **部分阶段尚未交付。** 本流程描述完整产品方向；成稿页布局、独立文字层和分享仍须按 PRD `PAGE-*` / `LETTER-*` / `PUBLISH-*`（均为 `proposed`）逐项确认。完整阶段及验证门槛见 [个人连载漫画工作台路线图](roadmap-complete-comic.md)。

1. 在作品设定集维护世界观、角色、场景和画风；新话继承前情摘要和未回收伏笔。
2. 作者审阅本话大纲与分镜，确认剧情顺序、对白和角色出场。
3. 逐格生成静态画面，单独重绘有问题的画格并保留选定版本。
4. **A1**：将画格排入可持久化的竖向条漫页（见下节）。
5. **A2**：对白与旁白作为独立文字对象排版和修改（本文件暂不展开）。
6. **A3**：成稿导出长图 / 多页图 / PDF；与 EXP 制作预览文案区分。
7. 继续下一话，复用已确认设定并更新连续性资料。
8. （后续可选）私密、可撤销的评审链接；公开阅读入口需另行确认。

## 规划屏幕流：阶段 A1 — 页与竖条排版（`proposed`）

> 对应 PRD **PAGE-01…03**。确认并 YAML-first 前不得实现。A1 **不含**独立字效编辑（A2）与成稿导出产品化（A3）。

### 目标

作者从「本话已有画格（当前选定版本）」走到「整话竖条成稿预览」，且页序/间距可保存；之后在 Studio 重绘某一格时，默认不丢页布局。

### 入口（三处，语义一致）

| 入口 | 行为 |
| --- | --- |
| 作品总览 → 某一话 | 「成稿排版」进入该话成稿模式（与「工作室」「阅读」并列） |
| Studio 工作区 | 本话有画格后提供「进入成稿排版」；不替换分镜/出图主路径 |
| 阅读页 | 「编辑条漫排版」跳转成稿模式（阅读页本身仍是 L1 浏览；A1 另立成稿预览） |

无画格时：入口禁用或引导先去 Studio 出图。

### 主路径

1. **进入成稿模式**  
   路由意向（规划）：`/projects/:id/layout/:episodeId`（名称可在确认时调整）。顶栏标明「成稿排版 · 第 N 话」，与 Studio「制作」区分。

2. **首次进入 / 尚无 Page**  
   - 提示：将按当前分镜顺序生成默认竖条页。  
   - 确认后：一格一槽（或产品确认的默认分段规则），模板固定为竖条（格高/间距用默认值）。  
   - 槽位引用各格**当前选定** `PanelVersion`，不存临时签名 URL。

3. **条漫画布（中央）**  
   - 竖向滚动预览整话；格按 Page/Slot 顺序堆叠。  
   - 选中一格：高亮；可拖拽改序、调格高/间距（PAGE-02/03）。  
   - 无图槽位显示占位与「回工作室出图」快捷入口。

4. **页/槽列表（侧栏或缩略条）**  
   - 显示页序与每页槽位数；支持合并/拆分页（MVP 可仅「全部一页竖条」+ 调距，拆分页可后置，但模型须支持有序 Page）。

5. **成稿预览**  
   - 「整话预览」：接近手机阅读宽度的只读竖条；文案标明这是**成稿预览**（布局已存），不是 EXP 下载、也不是 Studio 制作态。  
   - A1 预览可仍显示分镜里烘焙/附带的对白示意；**可编辑文字层属 A2**，此处不提供气泡编辑器。

6. **与 Studio 往返**  
   - 「回工作室」携带当前话上下文。  
   - 在 Studio 重绘并选定新版本后返回成稿：默认槽位改挂新 `PanelVersion`，**保留**页序与几何（PAGE-03）。  
   - 若分镜增删格：成稿模式提示「分镜已变，同步槽位」——可选自动按序重排未手动锁定的槽，或逐项确认；不得静默丢弃用户调过的间距而不提示。

7. **保存**  
   - 布局变更自动保存或显式保存（与 Studio hydrate 习惯对齐，确认时定一种）。  
   - 离开再进入：恢复同一 Page/Slot 状态。

### 明确不做（A1）

- 气泡/旁白独立对象的创建与样式编辑 → A2  
- 「导出成稿」长图/PDF 产品入口与 PUBLISH 文案 → A3（现有 EXP 制作预览导出仍走 L1，文案不改称成稿）  
- 固定网格页漫模板 → 后置  
- 公开分享链接 → PUBLISH-02

### 异常与空态

- 本话 0 画格：不能生成默认页。  
- 部分格无成功图像：可生成页，缺图槽占位；整话预览标注未就绪格。  
- 保存失败：保留本地未同步提示，不假装已持久化。  
- 无 Page 数据时的旧阅读页：行为不变（L1）；成稿预览仅在有 Page 或用户生成默认页后可用。

## 关键分支与异常

- 未确认角色/场景设定时允许继续，但提示生成结果尚未使用已确认的视觉依据。
- 文本模型输出无法解析时，后端做有限次数修复；仍失败则保留原输入并提示重试。
- 图像任务失败只影响对应任务，不阻塞其他分镜。
- 用户修改设定后，已有结果不静默重生成；提示用户哪些后续生成仍基于旧版本。
- 删除项目时显示影响范围，并要求用户确认。
