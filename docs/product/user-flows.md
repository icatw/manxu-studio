# 核心用户流程

## 当前主流程：个人连载到画格交付

### 1. 创建故事

用户可手填标题与梗概直接创建作品，或走 AI 季策划：输入创意 → 确认世界观/角色/大纲/伏笔 → 创建作品并进入作品总览。从总览进入某一话的工作区。

### 2. 建立视觉设定

用户从故事生成角色和场景档案。可以逐项修改外观、服装、性格和场景特征；用户确认后，状态显示为“已确认”，作为后续生成上下文。

角色档案可生成参考图。参考图版本与档案版本关联，替换参考图时保留旧版本。

### 3. 生成分镜脚本

用户选择故事范围、分镜数量和节奏倾向。系统基于故事及已确认设定生成分镜草稿。用户先审阅文本结构，可逐格编辑，也可以指定某一格重写。

### 4. 生成分镜画面

用户为选中的分镜发起生成。系统显示任务状态；用户可离开页面后返回查看。成功后将画面保存为该格的新版本；失败时显示原因并提供重试。

### 5. 局部修改与确认

用户可修改画面描述、对白或参考资产，再仅重绘当前格。旧版本保留，用户可比较并选定当前版本。确认后该格进入“已确认”。

### 6. 预览与交付

用户在页面预览顺序、对白和图像，调整分镜次序后导出。可选：本话竖向长图 PNG、本话按页高自动分页的 PNG ZIP、或制作资料 JSON。跨话合集在作品总览导出。导出使用当前选定版本。亦可进入阅读页竖排浏览当前话。

### 7. 续写下一话

用户在作品总览为当前话生成摘要后，再创建下一话并生成分镜。第 N 话（N>1）生成分镜前若上一话无摘要则被拒绝。生成时注入前情摘要与未回收伏笔。本话默认复用作品级角色/场景库；需要新人时以追加方式补充。整队重建角色或场景须单独确认。总览可「导出合集」勾选多话，下载 PNG ZIP 或 PDF。

## 规划流程：个人连载漫画创作

> **部分阶段尚未交付。** 本流程描述完整产品方向；成稿页布局、独立文字层和分享仍须按 PRD `PAGE-*` / `LETTER-*` / `PUBLISH-*`（均为 `proposed`）逐项确认。完整阶段及验证门槛见 [个人连载漫画工作台路线图](roadmap-complete-comic.md)。

1. 在作品设定集维护世界观、角色、场景和画风；新话继承前情摘要和未回收伏笔。
2. 作者审阅本话大纲与分镜，确认剧情顺序、对白和角色出场。
3. 逐格生成静态画面，单独重绘有问题的画格并保留选定版本。
4. 将画格排入竖向条漫布局；对白与旁白作为独立文字对象排版和修改。
5. 在手机阅读预览中检查顺序、文字和画面，导出长图、多页图片或 PDF。
6. 继续下一话，复用已确认设定并更新连续性资料。
7. （后续可选）创建私密、可撤销的评审链接；公开阅读入口需另行确认。

## 关键分支与异常

- 未确认角色/场景设定时允许继续，但提示生成结果尚未使用已确认的视觉依据。
- 文本模型输出无法解析时，后端做有限次数修复；仍失败则保留原输入并提示重试。
- 图像任务失败只影响对应任务，不阻塞其他分镜。
- 用户修改设定后，已有结果不静默重生成；提示用户哪些后续生成仍基于旧版本。
- 删除项目时显示影响范围，并要求用户确认。
