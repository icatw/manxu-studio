# 核心用户流程

## 当前主流程：个人连载到画格交付

### 1. 创建故事

用户可手填标题与梗概直接创建作品，或走 AI 季策划：输入创意 → 确认世界观/角色/大纲/伏笔 → 创建作品并进入作品总览。从总览进入某一话的工作区。总览「角色」页展示作品级角色库（全话共用）；与工作室「作品角色」为同一批数据。

### 2. 建立视觉设定

用户从故事生成角色和场景档案。可以逐项修改外观、服装、性格和场景特征；用户确认后，状态显示为“已确认”，作为后续生成上下文。

角色档案可生成参考图。参考图版本与档案版本关联，替换参考图时保留旧版本。

场景资产与角色重生解耦：暖启动只写分镜时，若场景库为空会同步补建；场景页空态可独立「根据本话生成场景」，也可跳过稍后再补。默认追加；整队重建须单独确认。未建场景不拦截出图，分镜页给软提示。

### 3. 生成分镜脚本

用户选择故事范围、分镜数量和节奏倾向。系统基于故事及已确认设定生成分镜草稿。用户先审阅文本结构，可逐格编辑，也可以指定某一格重写。

### 4. 生成分镜画面

用户为选中的分镜发起生成。**作品无角色时默认拦截出图**，引导先建角色；用户可显式确认「试画」后旁路。空镜（未挂角色）可直接出图。有角色但未确认/未定妆时允许出图并警告。系统显示任务状态；用户可离开页面后返回查看。成功后将画面保存为该格的新版本；失败时显示原因并提供重试。

### 5. 局部修改与确认

用户可修改画面描述、对白或参考资产，再仅重绘当前格。旧版本保留，用户可比较并选定当前版本。确认后该格进入“已确认”。

### 6. 预览与交付

用户在页面预览顺序、对白和图像，调整分镜次序后导出。可选：本话竖向长图 PNG、本话按页高自动分页的 PNG ZIP、或制作资料 JSON。跨话合集在作品总览导出。导出使用当前选定版本。亦可进入阅读页竖排浏览当前话。

### 7. 续写下一话

季策划确认后只物化第 1 话；其余大纲写在作品设定的「规划话大纲」中，续写时再建后续话。总览「续写下一话」以**最早尚无摘要的话**为 frontier：第 1 话无摘要时提示并打开该话；后续空壳话则打开该话工作室；全部已有摘要后才新建下一话。第 N 话（N>1）生成分镜前若上一话无摘要则被拒绝。生成时注入前情摘要与未回收伏笔。本话默认复用作品级角色/场景库；需要新人时以追加方式补充。整队重建角色或场景须单独确认。总览可「导出合集」勾选多话，下载 PNG ZIP 或 PDF。

## 规划流程：个人连载漫画创作

> PAGE / LETTER / **PUBLISH-01** 已确认；**PUBLISH-02** 仍 `proposed`。完整阶段见 [路线图](roadmap-complete-comic.md)。

1. 在作品设定集维护世界观、角色、场景和画风；新话继承前情摘要和未回收伏笔。
2. 作者审阅本话大纲与分镜，确认剧情顺序、对白和角色出场。
3. 逐格生成静态画面，单独重绘有问题的画格并保留选定版本。
4. **A1**：将画格排入可持久化的竖向条漫页（见下节）。
5. **A2**：对白与旁白作为独立文字对象排版和修改（见 A2 节）。
6. **A3**：成稿导出长图 / 多页图 / PDF；与 EXP 制作预览文案区分。
7. 继续下一话，复用已确认设定并更新连续性资料。
8. （后续可选）私密、可撤销的评审链接；公开阅读入口需另行确认。

## 屏幕流：阶段 A1 — 页与竖条排版（`confirmed`）

> 对应 PRD **PAGE-01…03**（已确认）与 OpenAPI `Layout`。A1 **不含**独立字效编辑（A2）与成稿导出产品化（A3）。

### 目标

作者从「本话已有画格（当前选定版本）」走到「整话竖条成稿预览」，且页序/间距可保存；之后在 Studio 重绘某一格时，默认不丢页布局。

### 入口（三处，语义一致）

| 入口 | 行为 |
| --- | --- |
| 作品总览 → 某一话 | 「成稿排版」进入该话成稿模式（与「工作室」「阅读」并列） |
| Studio 工作区 | 本话有画格后提供「进入成稿排版」；不替换分镜/出图主路径 |
| 阅读页 | 「编辑条漫排版」跳转成稿模式（阅读页本身仍是 L1 浏览；A1 另立成稿预览） |

无画格时：入口禁用或引导先去 Studio 出图。

### 主路径

1. **进入成稿模式**  
   路由意向（规划）：`/projects/:id/layout/:episodeId`（名称可在确认时调整）。顶栏标明「成稿排版 · 第 N 话」，与 Studio「制作」区分。

2. **首次进入 / 尚无 Page**  
   - 提示：将按当前分镜顺序生成默认竖条页。  
   - 确认后：一格一槽（或产品确认的默认分段规则），模板固定为竖条（格高/间距用默认值）。  
   - 槽位引用各格**当前选定** `PanelVersion`，不存临时签名 URL。

3. **条漫画布（中央）**  
   - 竖向滚动预览整话；格按 Page/Slot 顺序堆叠。  
   - 选中一格：高亮；可拖拽改序、调格高/间距（PAGE-02/03）。  
   - 无图槽位显示占位与「回工作室出图」快捷入口。

4. **页/槽列表（侧栏或缩略条）**  
   - 显示页序与每页槽位数；支持合并/拆分页（MVP 可仅「全部一页竖条」+ 调距，拆分页可后置，但模型须支持有序 Page）。

5. **成稿预览**  
   - 「成稿预览」：接近手机阅读宽度的只读竖条；文案标明这是**成稿预览**（布局已存），不是 EXP 下载、也不是 Studio 制作态。  
   - A1 仅布局与底图；**字效叠层见 A2**。

6. **与 Studio 往返**  
   - 「回工作室」携带当前话上下文。  
   - 在 Studio 重绘并选定新版本后返回成稿：默认槽位改挂新 `PanelVersion`，**保留**页序与几何（PAGE-03）。  
   - 若分镜增删格：成稿模式提示「分镜已变，同步槽位」——可选自动按序重排未手动锁定的槽，或逐项确认；不得静默丢弃用户调过的间距而不提示。

7. **保存**  
   - 布局变更自动保存或显式保存（与 Studio hydrate 习惯对齐，确认时定一种）。  
   - 离开再进入：恢复同一 Page/Slot 状态。

### 明确不做（A1）

- 气泡/旁白独立对象的创建与样式编辑 → A2  
- 「导出成稿」长图/PDF 产品入口与 PUBLISH 文案 → A3（现有 EXP 制作预览导出仍走 L1，文案不改称成稿）  
- 固定网格页漫模板 → 后置  
- 公开分享链接 → PUBLISH-02

## 屏幕流：阶段 A2 — 字效（`confirmed`）

> 对应 PRD **LETTER-01…03** 与 OpenAPI `Lettering`。A2 **不含**成稿导出产品化（A3）。主编辑面见 LETTER-03。

### 目标

作者在**工作室制作预览**条漫上编辑独立气泡/旁白；改字不重绘底图。成稿排版负责页结构；成稿预览只读叠字。

### 入口（主）

工作室顶栏「制作预览」→ 条漫审阅面。无布局时，「从分镜生成气泡」可先 bootstrap 默认竖条页再种气泡。

### 入口（次）

成稿排版 `/projects/:id/layout/:episodeId`：以槽序/格高/间距为主；字效只读或轻量引导回工作室，不作为学气泡第一课。

### 主路径

1. **从分镜生成气泡（可选）**  
   - 动作在工作室制作预览：「从分镜生成气泡」。  
   - 对「对白非空且尚无字效」的槽生成默认 `speech_bubble`（居上、宽约 60%、`font_size=md`、左右交替尾标可选）。  
   - **多人/多行对白拆成多个气泡**（LETTER-04），纵向错开。  
   - 默认不覆盖已有字效；显式「替换已有」才清空后重建。

2. **编辑字效**  
   - 制作预览中选中格/字效 → 改文案、位、宽、字号、增删气泡/旁白。  
   - **桌面拖动**气泡/旁白改位置（LETTER-06）；松手保存；百分比表单仍可精调。  
   - 手工「新增气泡/旁白」写入「（填写对白/旁白）」占位，**不**克隆整段分镜对白。  
   - 不能把文案存成壳词「旁白」「对白」「气泡」（LETTER-05）。  
   - 几何以槽内百分比存储；保存后刷新仍在。  
   - 工作室画布卡与制作预览：有 Lettering 叠 Lettering；无则分镜对白占位（可区分未落成）。  
   - 分镜列表摘要优先字效文案；检查器区分「制作态对白」与成稿字，不一致时可「用字效回写脚本」（LETTER-07）。

3. **成稿预览（排版页）**  
   - 只读竖条：底图 + 叠字；标明「成稿预览 · 含字效」。  
   - 不写回 PNG；「导出成稿」见 A3。

4. **与分镜 / 重绘**  
   - 重绘换版：槽位改挂新图，**字效保留**。  
   - 分镜对白变更：不自动改 Lettering；用户可再跑「生成气泡」或手改。

### 明确不做（A2）

- 页级游离字效、人名框、爆炸泡、字体上传  
- 用模型绘字 OCR 回填对白

### 异常与空态

- 无布局：种气泡流程先 bootstrap；否则引导生成竖条页。  
- 空对白槽：生成气泡跳过；可手加旁白。  
- 删槽：级联删字效。  
- 跨账户：404，不暴露存在性。

### A1 布局空态（仍适用）

- 本话 0 画格：不能生成默认页。  
- 部分格无成功图像：可生成页，缺图槽占位；整话预览标注未就绪格。  
- 保存失败：保留本地未同步提示，不假装已持久化。  
- 无 Page 数据时的旧阅读页：行为不变（L1）；成稿预览仅在有 Page 或用户生成默认页后可用。

## 屏幕流：阶段 A3 — 成稿导出（`confirmed`）

> 对应 PRD **PUBLISH-01** 与 OpenAPI `Publish`。不含 PUBLISH-02 分享链接。

### 目标

作者将本话 Page + Lettering 合成为可带走的成稿文件；与工作室「制作导出」文案与行为可区分。

### 入口

成稿排版页顶栏「导出成稿 ▾」（长图 PNG / 分页 ZIP / PDF）。无布局时禁用并提示先生成竖条页。

### 主路径

1. 确认竖条布局与字效（可先成稿预览）。  
2. 选择格式发起异步任务；成功后下载，文件名含「成稿」与正确后缀。  
3. 合成顺序与格高/间距跟布局；字效仅 Lettering，无分镜对白回退。

### 明确不做（A3）

- CBZ；合集成稿；公开/私密分享链接（PUBLISH-02）  
- 把 EXP「制作导出」改称成稿

### 异常

- 无布局：409。  
- 缺图槽：灰底占位，不中断整话导出。  
- 跨账户：404。

## 关键分支与异常

- 作品零角色：出图默认拦截（`CAST_REQUIRED`）；试画须 `acknowledge_trial`。
- 有角色但未确认/未定妆：允许出图，提示生成结果尚未使用已确认视觉依据。
- 默认新建话为 8 格；画布展示本话梗概，鼓励先审对白与剧情作用再批量出图。
- 文本模型输出无法解析时，后端做有限次数修复；仍失败则保留原输入并提示重试。
- 图像任务失败只影响对应任务，不阻塞其他分镜。
- 用户修改设定后，已有结果不静默重生成；提示用户哪些画格/话仍基于旧版本（IMPACT-CAST / IMPACT-BIBLE：保存响应带影响摘要，工作室软提示；作者自行决定重绘）。
- 删除项目时显示影响范围，并要求用户确认。
