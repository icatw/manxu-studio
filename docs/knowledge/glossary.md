# 产品术语表

| 术语 | 定义 | 边界 |
| --- | --- | --- |
| 作品 / 项目 Project | 一部连载漫画及其创作资料的根容器；产品文案称「作品」，API 资源为 `Project` | 不是团队/组织账号 |
| 话 / 故事单元 Episode | 可独立拆解为分镜的一话；产品文案称「第 N 话」，API 资源为 `Episode` | 同一作品可有多个话，角色/场景挂在作品级 |
| 设定集 Bible | 作品级世界观、画风规则、负向提示词与 style seed | 与单话梗概区分 |
| 伏笔 Plot Thread | 跨话埋设与回收的剧情线索 | 不是分镜字段 |
| 话摘要 Episode Summary | 本话完成后的短摘要，供下一话续写上下文 | 不等于话大纲 synopsis |
| 角色资产 Character Asset | 可在项目多个分镜中复用的结构化人物设定及参考图 | 不是模型微调或绝对一致性保证 |
| 场景资产 Location Asset | 可供多个分镜引用的场景设定及参考图 | 与某一格的即时背景描述区分 |
| 分镜 Storyboard Panel | 对故事中一个视觉时刻的制作描述 | 包含镜头、构图、动作、情绪、对白等字段 |
| 画格 Panel Image | 某个分镜的图像候选或当前选中图像 | 不等同于漫画最终排版页 |
| 生成任务 Generation Task | 一次可追踪、可查询的文本/图像/导出操作 | 重试创建新任务，不覆写原任务 |
| 已确认 Approved | 创作者当前接受的设定或分镜版本 | 更新设定不应静默改写依赖它的历史产物 |
| 连载工作台 Serial comic workspace | 面向个人作者的作品、话、设定、分镜和画格管理体验；当前已交付到分镜/画格阶段 | 产品目标是静态图片漫画；不包含动态漫/视频成片 |
| 漫画成稿 Comic finishing | **规划中**：在分镜和画格之上完成页面布局、独立字效层、阅读预览和成品导出 | 不是视频成片；不是专业排版软件全家桶；需求见 PRD `proposed` 与 `roadmap-complete-comic.md` |
| 完整漫画 Complete comic | 产品方向中的最低交付物：可阅读页面 + 可独立修改对白 + 静态图片/PDF 导出，竖向条漫优先 | 成稿页布局和独立文字层当前未作为 `confirmed` 交付承诺 |
