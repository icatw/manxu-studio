# v0 工作流迁移

## 目标

将 `icatw/man-xustudio` 的核心工作区交互迁入 React/Vite 前端，接入 FastAPI、PostgreSQL 与 YAML-first API 契约，完成项目到导出的可演示流程。v0 参考基线：`c41f728`。

## 已确认范围

- 首轮包含最小项目列表/创建/打开/删除、故事单元、角色与场景、分镜编辑、异步画面生成、图像版本选择、预览与导出。
- 首轮不包含连载季策划、连续剧情线、章节摘要和阅读页。
- 只迁移代码、UI 与交互，不导入 v0 数据库或浏览器数据。
- 保留 React/Vite + FastAPI；不迁移 Next.js 服务端、Drizzle 和 Next API Routes。

## 验收

- 用户能创建项目和故事单元，刷新后仍能打开并编辑。
- 用户能编辑/确认角色与场景，生成、编辑、排序、增删分镜。
- 单格图像生成状态持久可查；失败可重试；新图形成独立历史版本且可选为当前版本。
- 用户能预览并导出 PNG 和制作资料。
- 浏览器不直接调用模型供应商；密钥仅由后端读取。
- OpenAPI YAML 是唯一手工维护的 HTTP 契约源，生成类型无差异。
